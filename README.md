# luxe-beauty-expo
# Luxe Beauty Expo

A responsive event registration website developed using HTML, CSS, Bootstrap, PHP, and MySQL. This project allows users to register, log in securely, book event tickets, and manage their profile through a modern and user-friendly interface.

---

# Features

- Responsive Landing Page
- User Registration & Login
- Secure Password Hashing
- Session Management
- User Profile
- Event Ticket Booking
- My Bookings Dashboard
- MySQL Database Integration
- Responsive Bootstrap Design

# Installation

1. Clone the repository

```bash
git clone https://github.com/yourusername/luxe-beauty-expo.git
```

2. Move the project to the **htdocs** folder.

3. Import the SQL database into phpMyAdmin.

4. Update database credentials in `db.php`.

5. Start Apache and MySQL using Laragon.

6. Open:

```
http://localhost/luxe-beauty-expo/
```
